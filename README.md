# coolmoAI 文档

coolmoAI 官方文档站，基于 [VitePress](https://vitepress.dev/) 构建。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 文档结构

```
docs/
├── guide/
│   ├── zh/          # 中文文档
│   └── en/          # English docs
└── .vitepress/
    └── config.mts   # VitePress 配置
```

## 在线地址

- 文档站：[coolmoai.cc/docs](https://coolmoai.cc/docs)
- API 控制台：[coolmoai.cc](https://coolmoai.cc)
