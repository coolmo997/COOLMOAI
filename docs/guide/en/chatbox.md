# ChatBox Configuration

ChatBox is a cross-platform desktop AI chat client for Windows, macOS, and Linux.

## Download & Install

Visit the [ChatBox website](https://chatboxai.app) to download the installer for your platform.

## Configuration Steps

1. Open ChatBox → click **Settings** in the bottom left
2. Select **OpenAI API** as the AI Model Provider
3. Fill in:

| Field | Value |
|-------|-------|
| API Domain | `https://coolmoai.cc` |
| API Key | `sk-xxxxxxxxxxxx` |
| Model | Enter model name manually, e.g. `gpt-4o` |

4. Click **Save**

::: info
The API Domain field in ChatBox does **not** need a `/v1` suffix — the app appends it automatically.
:::

## Verify Configuration

After saving, send a message in the chat. If you receive a normal reply, the configuration is successful.
