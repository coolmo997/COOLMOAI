公开页面与使用边界

coolmoAI 是面向开发者的 AI API 接入服务。公开文档提供 API Key、Base URL、工具配置、SDK 示例、API 参考和错误排查内容。可用模型、价格、额度、账号权限、接口参数和服务限制，以最新文档、控制台页面和接口返回为准。

当前仓库没有 OpenClaw 和 CC-SITE 的专项配置资料，因此对应页面仅提供配置前检查和通用文档入口，不将未经核对的协议或兼容性描述为已验证事实。

常见问题

coolmoAI 如何开始使用？

先注册或登录，进入控制台创建 API Key，再按照快速开始文档配置 Base URL 和模型名称，使用最小请求验证连接。

API Key 从哪里获取？

API Key 从 coolmoAI 控制台创建和复制。不要将真实 Key 写入公开仓库、前端代码、日志或截图。

支持哪些模型？

模型可用性取决于当前控制台、账号权限和接口返回，建议通过控制台或 /v1/models 核对实时模型列表。

出现 401、429、502 或 503 怎么办？

先检查 API Key、权限、请求频率、模型名称和上游服务状态，再参考公开 FAQ 进行排查。
